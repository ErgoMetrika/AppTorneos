=====================================================
TORNEO 90' - TECNOLOGÍAS COMPLEMENTARIAS E INSTALACIÓN
=====================================================

TECNOLOGÍAS UTILIZADAS
----------------------

Base de datos y servidor
  - Supabase: base de datos PostgreSQL en la nube, con login de usuarios
    (Auth), API automática y reglas de seguridad por fila (RLS).
    Reemplaza al servidor PHP + MySQL: no hay un backend propio.
  - PostgreSQL: motor de la base de datos (tablas, funciones y triggers).
  - Supabase CLI: herramienta para aplicar los cambios de la base.

Frontend (la página web)
  - React 19: librería para armar la interfaz.
  - TypeScript: JavaScript con tipos.
  - Vite: servidor de desarrollo y compilación.
  - Tailwind CSS 4 + daisyUI: estilos.
  - React Router: navegación entre páginas.
  - TanStack Query: carga y actualización de datos desde Supabase.
  - React Hook Form + Zod: formularios y validación.
  - supabase-js: librería para conectarse a Supabase.
  - Radix UI, lucide-react, sonner, date-fns: ventanas, íconos, avisos y fechas.
  - Google Maps (mapa embebido, sin clave): ubicación de cada torneo.

Publicación
  - Vercel: hosting gratuito de la página. Cada cambio subido a GitHub se
    publica solo.
  - GitHub: repositorio del código.

REQUISITOS
----------
  - Node.js 22 o superior: https://nodejs.org (versión LTS).
    Trae incluido "npm", que es lo que se usa para instalar y correr la app.
  - Un navegador actualizado (Chrome, Edge, Firefox o Safari).

No hace falta instalar XAMPP, PHP ni MySQL: la base está en Supabase.

INSTALACIÓN Y EJECUCIÓN
-----------------------
  1. Descomprimir 02_Proyecto/Torneo90_proyecto_completo.zip.
     Queda la carpeta Torneo90 con "frontend" y "backend".

  2. Abrir una terminal en la carpeta del front:
        cd Torneo90/frontend

  3. Crear el archivo de configuración ".env":
       - Copiar el archivo Torneo90/backend/.env.example dentro de
         Torneo90/frontend y renombrarlo a ".env".
       - Ya trae la dirección y la clave pública de la base en la nube.

  4. Instalar las dependencias (crea la carpeta node_modules, tarda
     alrededor de un minuto):
        npm install

  5. Levantar la app:
        npm run dev

  6. Abrir en el navegador la dirección que muestra la terminal
     (normalmente http://localhost:5173).

Para generar la versión final (la que se publica):
        npm run build

(Si se tiene instalado pnpm, también funciona: pnpm install / pnpm dev.)

También se puede ver sin instalar nada en:
        https://app-torneos-three.vercel.app

BASE DE DATOS PROPIA (OPCIONAL)
-------------------------------
Si se quiere usar una base nueva en vez de la que ya está en la nube, ver
01_Base_de_datos/LEEME_base_de_datos.txt y poner en el ".env" la URL y la
anon key del proyecto nuevo:
        VITE_SUPABASE_URL=...
        VITE_SUPABASE_ANON_KEY=...
