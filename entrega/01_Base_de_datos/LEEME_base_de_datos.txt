=====================================================
TORNEO 90' - BASE DE DATOS
=====================================================

Motor: PostgreSQL, alojado en Supabase (plan gratuito).
La base ya está funcionando en la nube, conectada a la app publicada:
    Proyecto Supabase: torneos-futbol
    URL de la API:     https://rcdnticmpjhiajjmoivo.supabase.co

ARCHIVOS
--------
Torneo90_base_de_datos_completa.sql
    Todo en un solo archivo y en el orden en que se aplica:
      1. Estructura: 7 tablas (usuarios, equipos, jugadores, torneos,
         torneo_equipos, partidos, contactos), tipos y restricciones.
      2. Funciones (RPC) con las reglas de negocio: inscribirse, generar la
         llave, cargar resultados, buscar torneos privados por código, etc.
      3. Seguridad (RLS): quién puede ver y modificar cada fila.
      4. Migraciones posteriores (mejoras hechas durante el desarrollo).
      5. Datos de prueba: usuarios, equipos, torneos e inscripciones.

Torneo90_esquema_original_MySQL.sql
    Primera versión del esquema, en MySQL (XAMPP). Se dejó como referencia;
    la app usa la versión PostgreSQL de arriba.

Torneo90_diagrama_entidad_relacion.html
    Diagrama de las tablas y sus relaciones. Se abre con el navegador.

CÓMO IMPORTAR LA BASE
---------------------
El archivo usa funciones propias de Supabase (por ejemplo el esquema "auth"
para el login), así que se importa en un proyecto de Supabase:

  1. Crear una cuenta gratis en https://supabase.com y un proyecto nuevo.
  2. En el panel del proyecto ir a "SQL Editor" -> "New query".
  3. Pegar todo el contenido de Torneo90_base_de_datos_completa.sql y
     tocar "Run".
  4. En "Project Settings" -> "API" copiar la "Project URL" y la "anon public
     key" para conectar el front (ver 03_Tecnologias_e_instalacion.txt).

Para usar la base que ya está en la nube no hace falta importar nada:
el proyecto ya viene configurado para conectarse a ella.
